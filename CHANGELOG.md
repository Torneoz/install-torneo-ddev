# Changelog

All notable changes to this project will be documented in this file.

## Unreleased

- Expanded the project documentation with complete installation,
  configuration, verification, troubleshooting, maintenance, security, and
  release-testing instructions.

## 1.0.0 - 2026-08-01

- Added a reproducible Drupal CMS AI test harness recipe.
- Enabled AI Agents, Assistant API, Chatbot, Dashboard, API Explorer, Costs,
  Observability, CKEditor integration, Image Studio, OpenAI, and Grok.
- Added a preconfigured chatbot assistant, agent, DeepChat block, Canvas
  components, provider defaults, permissions, and environment-backed keys.
- Updated the renamed Grok provider module to `drupal/grok` 1.0.0-alpha9.
- Added reproducible compatibility fixes for Grok configuration, AI Chatbot
  Canvas schemas and CSRF handling, and Trash validation during installation.
- Added a single-command destructive rebuild and post-build verification.
